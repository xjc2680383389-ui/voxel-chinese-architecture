# 丹宸 · 体素中国古典建筑群

Three.js 实现的中式古典建筑群场景，Minecraft 式体素块拼接，浏览器打开即进入场景。
纯前端，无后端依赖。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

其他命令：

```bash
npm run build      # 产出 dist/
npm run preview    # 本地预览构建产物 http://127.0.0.1:4173
```

> ES Module 无法用 `file://` 直接打开，必须经由 dev / preview 的本地服务。

## 交互

- 左键拖拽旋转，滚轮推拉，右键平移；载入时有一段推入镜头，任意操作即接管
- 右上角「时辰」切换 晨 / 午 / 昏 / 夜 四套光照与天空（默认昏）
- 夜间灯笼、香炉火星、塔刹会亮起自发光
- 左下角实时显示体素总数与帧率

## 场景构成

中轴对称九进院落，自南而北：

| 建筑 | 位置 | 形制 |
| --- | --- | --- |
| 山门 | 中轴南端，嵌于围墙 | 三洞殿式门，青砖，歇山顶 |
| 琉璃影壁 | 山门内 | 悬山顶，琉璃心 |
| 钟楼 / 鼓楼 | 前院东西对称 | 砖砌台基开券洞，上建歇山楼 |
| 牌楼 | 中轴，院落分界 | 四柱三间，三楼 |
| 配殿 ×2 | 中院东西对称 | 五开间，歇山顶，绿琉璃 |
| **主殿** | 中轴核心，体量最大 | 九分位七开间，**重檐庑殿顶**，三重白玉石台基，金琉璃瓦 |
| 游廊 | 主殿院四周 | 悬山长廊，围合院落 |
| 藏经阁 | 中轴北端 | 重檐歇山，两层 |

## 实现要点

- `src/voxel.js` — 体素容器。所有几何写入同一个 `Map`，键为打包后的整数坐标，
  因此天然去重、后写覆盖先写（开洞、贴面装饰都依赖这一点）；最终只生成
  **一个 `InstancedMesh`**，整个建筑群与发光体共 2 个 draw call。
- `src/roofs.js` — 屋顶形制。庑殿 / 歇山 / 悬山 / 攒尖分层内收，
  用 `pow(t, k)` 曲线模拟「举折反宇」，檐角按 `|x|·|z|` 权重抬升得飞檐翘角；
  瓦垄以每 3 格压暗一格的方式在环带上着色。
- `src/buildings.js` — `makeHall` 为通用殿阁体（台基、柱网、墙体、门窗、斗拱、屋顶），
  山门、配殿、主殿、藏经阁共用参数化生成。所有建筑先在局部坐标系以原点为中心、
  正面朝 `+z` 建造，再由 `stamp()` 旋转镜像后盖到场景，保证中轴严格对称。
- `src/environment.js` — 场地铺装用一张程序化 `CanvasTexture`（1 体素 = 2 px，
  Nearest 放大）绘制草地、御路、庭院、园圃，避免地面消耗体素。

## 性能

- 体素约 7.9 万个，集中在 2 个 InstancedMesh 内
- 阴影贴图只渲染一次：`shadowMap.autoUpdate = false`，仅切换时辰时置 `needsUpdate`
- 实测（Chrome，内嵌浏览器 531×232 视口）稳定 240 fps；旋转视角无掉帧
- 单块 BoxGeometry + `MeshStandardMaterial`，自发光体走 `MeshBasicMaterial` 独立通道
